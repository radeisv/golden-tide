# Golden Tide — GTA-style cover studio

Turn any photo into a GTA 6-style poster: six photo panels with role callouts, a giant striped "GOLDEN TIDE" title over the hero, a press-quote bar, billing block, seal and barcode — then export it as a PNG in 1920×1080, 1080×1350 or 1080×1080.

## How it works

1. Open `app/index.html` (or run `node serve.ts` and open http://localhost:8080).
2. Pick a panel, upload your own photo, crop it with zoom / pan / flip, or click the cover to set the focal point. One photo can fill all six panels, each re-cropped on its own.
3. Edit the title, script subtitle, quote, roles and billing, pick a grade preset (Golden Hour, Neon Nights, Vice Pastel, Noir Gold), tune Treatment and Poster Ink.
4. Export a PNG in any of the three post sizes.

Everything runs offline in the browser: no network requests, no uploads. The six sample photos were made with an image model; the fonts (Anton, Pacifico) are under the SIL Open Font License. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty.

## Run it locally

```sh
node serve.ts
# then open http://localhost:8080
```
